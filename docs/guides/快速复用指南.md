# 文档框架快速复用指南 (v2.0)

## 🚀 5分钟快速复用

### 第一步: 复制核心文件 (2分钟)

```bash
# 在新项目中创建目录
cd <新项目路径>
mkdir -p docs/templates docs/guides docs/requirements

# 从本项目复制核心文件
SOURCE="<本项目路径>/docs"

# 1. 复制模板库
cp $SOURCE/templates/*.md docs/templates/

# 2. 复制使用指南
cp $SOURCE/guides/*.md docs/guides/

# 3. 复制需求索引
cp $SOURCE/requirements/README.md docs/requirements/README.md

# 可选: 复制示例需求作为参考（改名避免混淆）
cp -r $SOURCE/requirements/REQ-001-版本迁移 docs/requirements/.example-REQ-001
```

### 第二步: 初始化 Git (1分钟)

```bash
git add docs/
git commit -m "docs: 初始化三层文档框架 v2.0

- 添加 PROJECT-STATUS 项目仪表盘模板
- 添加精简版任务模板
- 添加使用指南和更新指南
"
```

**完成!** 现在你的新项目已经有了完整的文档框架 v2.0。
