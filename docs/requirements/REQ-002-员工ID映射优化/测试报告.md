## 问题与修复记录

### 问题1: Next.js 编译错误 - "Server actions must be async functions"

**发现时间**: 2025-11-08 测试阶段

**错误信息**:
```
Error: Server actions must be async functions
  lib/custom/employee-project.js:40
  export function generateFriendlyProjectName(employeeId) {
```

**原因分析**:
- 在 `lib/custom/employee-project.js` 文件顶部添加了 `'use server'` 指令
- Next.js 要求所有带 `'use server'` 的导出函数必须是异步函数
- 但 `generateFriendlyProjectName()` 是纯函数,不需要异步

**解决方案**:
移除 `'use server'` 指令,因为该文件不是 React Server Actions,而是普通的服务器端工具函数

**修复代码**:
```javascript
// ========== CUSTOM START ==========
// 定制说明: 员工项目专用业务逻辑封装
// 修改日期: 2025-11-08 | 需求: REQ-002
// 功能: 通过externalId管理员工项目,支持自定义名称,自动生成友好名称
// 注意: 这是服务器端工具函数,不是React Server Actions,因此不使用'use server'
// ========== CUSTOM END ==========

import { db } from '@/lib/db/index';
```

**影响范围**: TASK-002 自定义代码层实现

**状态**: ✅ 已修复

### 问题2: curl 测试中文参数失败

**发现时间**: 2025-11-08 测试阶段

**表现**:
测试用例2和5返回 400 Bad Request

**原因分析**:
- curl 命令行中直接使用中文字符未进行URL编码
- shell脚本中的 `curl "...?name=中文"` 导致参数传递失败

**解决方案**:
使用 curl 的 `--data-urlencode` 参数自动进行URL编码:
```bash
curl --globoff -G --data-urlencode "name=自定义项目名称" \
  "http://localhost:1717/api/projects/employee/test-custom-name"
```

**影响范围**: 测试脚本,不影响实际代码

**状态**: ✅ 已修复
