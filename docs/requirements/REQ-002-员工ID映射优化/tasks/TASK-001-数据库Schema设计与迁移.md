## 四、技术方案

### 4.1 Schema 设计

**字段定义**:
```prisma
model Projects {
  id                   String    @id @default(nanoid(12))
  name                 String
  description          String

  // ========== CUSTOM START ==========
  // 定制说明: 为员工API映射功能添加外部系统ID字段
  // 修改日期: 2025-11-08 | 需求: REQ-002
  // 用途: 通过externalId映射外部系统(如employeeId)到项目,释放name为展示用途
  externalId           String?                @unique
  // ========== CUSTOM END ==========

  // ... 其他字段
}
```

**设计说明**:
- `String?`: 可选字段,向后兼容现有项目
- `@unique`: 唯一约束,确保同一个 employeeId 只能映射一个项目
- 索引: Prisma 自动为 @unique 字段创建索引,优化查询性能

### 4.2 迁移策略

**兼容性考虑**:
- 字段为可选 (String?),现有项目 externalId = null
- 不影响现有业务逻辑
- 普通用户创建的项目不需要设置 externalId

**回滚方案**:
- 如需回滚,可以删除 externalId 字段
- 由于是可选字段,删除不会导致数据丢失
