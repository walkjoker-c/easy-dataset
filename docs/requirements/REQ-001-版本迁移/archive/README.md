# Archive 目录说明

## 📁 目录用途

本目录用于存放 **详细执行日志** 和 **详细分析报告**，这些文档包含完整的技术细节、代码示例、数据流图等，但不作为日常查阅的主要文档。

根据 **AI协作文档框架 v2.0** 的精简记录原则，主文档（PROJECT-STATUS、TASK文档等）只保留关键摘要和决策，详细内容归档到此目录。

## 🎯 使用指南

### 何时查阅归档文档？

**推荐查阅主文档**：
- 快速了解项目状态 → [00-PROJECT-STATUS.md](../00-PROJECT-STATUS.md)
- 查看任务摘要 → [tasks/](../tasks/)


## 🔄 归档原则（供框架使用者参考）

### 何时归档？

1. **执行日志超过500行** → 移动到 archive/详细执行日志.md
2. **任务文档超过300行** → 精简主文档，详细内容移到 archive/TASK-XXX-详细报告.md
3. **包含大量代码示例/数据流图** → 归档到 archive/

### 归档格式

- **主文档**：摘要 + 关键决策 + 问题汇总 + 链接到归档
- **归档文档**：完整细节 + 代码示例 + 技术分析

**示例**：
```markdown
## 四、分析结果摘要

### 4.1 总体统计
- 总改动文件数: 33个
- 核心功能: 4个

> 📄 **详细分析报告**（含完整文件清单、代码变更详情）：
> 查看 [archive/TASK-001-详细分析报告.md](../archive/TASK-001-详细分析报告.md)
```
