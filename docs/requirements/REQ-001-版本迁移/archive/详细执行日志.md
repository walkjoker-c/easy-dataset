### Q2: 如何回退到之前的版本?
**A**:
```bash
# 查看提交历史
git log --oneline

# 回退到特定commit
git reset --hard <commit-id>

# 或者创建新分支从某个commit开始
git checkout -b hotfix/<version> <commit-id>
```

### Q3: 误操作如何恢复?
**A**:
```bash
# 查看所有操作历史
git reflog

# 恢复到某个操作之前
git reset --hard HEAD@{n}
```
