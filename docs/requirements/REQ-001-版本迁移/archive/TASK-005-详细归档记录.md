## 三、技术方案

### 3.1 技术路线
- **Git分支合并**: 使用 `--no-ff` 模式保留完整合并历史
- **版本标签**: 使用带注释的 tag (`-a`) 包含详细发布说明
- **文档格式**: 使用 Markdown 格式,结构化组织

### 3.2 版本标签命名规范
- **格式**: `vX.Y.Z-custom-N`
  - X.Y.Z: 对应官方版本号 (1.6.0)
  - custom-N: 定制版本号,递增 (1.0, 1.1, ...)
- **示例**: v1.6.0-custom-1.0
