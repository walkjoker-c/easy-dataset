## 📋 问题背景

在测试管理员功能时,用户发现两个关键问题:

### 问题1: 根目录未要求登录
- **问题描述**: 访问根目录(/)时未要求登录,直接显示项目列表
- **问题级别**: 🔴 高 - 安全隐患
- **发现时间**: 2025-11-18
- **原因分析**:
  - `app/page.js` 是客户端组件,未进行服务端Session检查
  - 仅依赖API鉴权,但前端页面可直接访问
  - 用户可以看到项目列表UI,虽然API会拦截,但体验不佳

### 问题2: 缺少登出按钮
- **问题描述**: 登录后界面上没有登出按钮,用户无法主动登出
- **问题级别**: 🟡 中 - 体验问题
- **发现时间**: 2025-11-18
- **原因分析**:
  - `TASK-009` 只实现了登录页面,未在主页面添加登出功能
  - `/api/admin/logout` API已实现,但前端未调用
  - 用户只能通过清除Cookie或关闭浏览器退出

---

## 🎯 解决方案

### 方案A: 页面级Session检查 (✅ 采用)

**技术方案**:
1. 将 `app/page.js` 从客户端组件改为服务端组件
2. 在服务端使用 `getSession()` 检查管理员Session
3. 未登录时使用 `redirect('/admin/login')` 重定向
4. 登录后渲染客户端组件(包含原有页面逻辑)

**优点**:
- ✅ 服务端渲染时直接拦截,安全性更高
- ✅ 用户体验好,直接跳转登录页
- ✅ 符合Next.js 14 App Router最佳实践
- ✅ 保持后端API鉴权不变

**缺点**:
- ⚠️ 需要拆分客户端逻辑到独立组件
- ⚠️ 页面需要动态渲染(无法静态优化)

**工作量**: 1-2小时

### 方案B: 客户端检查(未采用)

**技术方案**:
1. 在 `app/page.js` 的 `useEffect` 中调用 `/api/admin/check`
2. 未登录时客户端跳转到登录页

**优点**:
- ✅ 改动小,无需拆分组件

**缺点**:
- ❌ 客户端检查,安全性较低
- ❌ 页面会先渲染再跳转,用户体验差(闪烁)
- ❌ SEO不友好

**工作量**: 0.5小时

### 登出按钮方案

**技术方案**:
1. 在项目列表页面(`HomeClient.js`)顶部添加管理员状态栏
2. 显示"管理员已登录"标签
3. 提供"登出"按钮
4. 点击后调用 `/api/admin/logout` 并刷新页面

**UI设计**:
- 位置: 页面顶部,Hero Section下方
- 样式: 使用Material-UI的Chip + Button组件
- 颜色: 成功绿色(success.light)
- 图标: AdminPanelSettingsIcon + LogoutIcon

## 🛠️ 实施内容

### 1. 修改 `app/page.js` (页面级登录保护)

**原有代码**:
- 客户端组件('use client')
- 包含所有页面逻辑(useState、useEffect、JSX)
- 无登录检查

**修改后**:
```javascript
// ========== CUSTOM START ==========
// CUSTOM: 页面级登录保护 - REQ-004 补充需求
// ========== CUSTOM END ==========

import { redirect } from 'next/navigation';
import { getSession } from '@/lib/custom/auth/session';
import HomeClient from '@/components/home/HomeClient';

// 告诉Next.js此页面需要动态渲染(因为使用了cookies)
export const dynamic = 'force-dynamic';

export default async function Home() {
  // 检查管理员Session
  const session = await getSession();

  // 如果未登录,重定向到登录页
  if (!session.isAdmin) {
    console.log('[Home Page] User not logged in, redirecting to /admin/login');
    redirect('/admin/login');
  }

  console.log('[Home Page] Admin logged in, rendering page');

  // 渲染客户端组件(原有的页面逻辑)
  return <HomeClient />;
}
```

**关键变更**:
- ✅ 改为服务端组件(移除'use client')
- ✅ 添加 `export const dynamic = 'force-dynamic'` (支持cookies)
- ✅ 使用 `getSession()` 检查登录状态
- ✅ 使用 `redirect()` 重定向到登录页
- ✅ 委托客户端组件渲染页面逻辑

### 2. 创建 `components/home/HomeClient.js` (客户端逻辑)

**功能**:
- 从 `app/page.js` 拆分出的客户端逻辑

- 包含原有的所有JSX渲染逻辑

**新增逻辑 - 登出功能**:
```javascript
/**
 * 处理管理员登出
 */
const handleLogout = async () => {
  setLoggingOut(true);

  try {
    const response = await fetch('/api/admin/logout', {
      method: 'POST',
    });

    if (response.ok) {
      console.log('[Home Client] Logout successful, redirecting to login page');
      // 登出成功,刷新页面(服务端会重定向到登录页)
      router.refresh();
    } else {
      console.error('[Home Client] Logout failed:', await response.text());
      alert('登出失败,请重试');
    }
  } catch (error) {
    console.error('[Home Client] Logout error:', error);
    alert('登出失败,请检查网络连接');
  } finally {
    setLoggingOut(false);
  }
};
```

## 🔍 关键技术点

### 1. Next.js 14 服务端组件登录检查

**核心代码**:
```javascript
export const dynamic = 'force-dynamic'; // 强制动态渲染

export default async function Home() {
  const session = await getSession(); // 服务端调用
  if (!session.isAdmin) {
    redirect('/admin/login'); // 服务端重定向
  }
  return <HomeClient />;
}
```

**技术要点**:
- ✅ 服务端组件可以直接使用 `async/await`
- ✅ `getSession()` 在服务端调用,访问 `cookies()`
- ✅ `redirect()` 会抛出 `NEXT_REDIRECT` 错误触发重定向
- ✅ `dynamic = 'force-dynamic'` 告诉Next.js跳过静态优化
- ✅ App Router的重定向是客户端处理(307临时重定向)

### 2. 客户端登出流程

**核心代码**:
```javascript
const handleLogout = async () => {
  const response = await fetch('/api/admin/logout', { method: 'POST' });
  if (response.ok) {
    router.refresh(); // 刷新页面,服务端会重定向
  }
};
```

**技术要点**:
- ✅ 调用 `/api/admin/logout` 销毁Session
- ✅ 使用 `router.refresh()` 刷新页面(不是 `router.push()`)
- ✅ 刷新后服务端检测到未登录,触发 `redirect('/admin/login')`
- ✅ 用户体验: 点击登出 → 刷新 → 自动跳转登录页

### 3. 组件拆分策略

**拆分原因**:
- ✅ 服务端组件不能使用 `useState`、`useEffect` 等客户端API
- ✅ 客户端组件不能使用 `cookies()`、`redirect()` 等服务端API
- ✅ 需要明确边界: 服务端负责鉴权,客户端负责交互

**拆分方案**:
```
app/page.js (服务端组件)
  ↓ 检查Session
  ↓ 未登录 → redirect('/admin/login')
  ↓ 已登录 → 渲染客户端组件
  ↓
components/home/HomeClient.js (客户端组件)
  ↓ 状态管理(useState)
  ↓ 副作用(useEffect)
  ↓ 交互逻辑(onClick)
  ↓ UI渲染(JSX)
```
