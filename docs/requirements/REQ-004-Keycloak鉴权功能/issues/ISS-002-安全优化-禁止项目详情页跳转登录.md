## 📋 问题描述

### 现象

当未授权用户（无管理员Session也无Token）访问项目详情页时（如 `http://localhost:1717/projects/0P4Tj_DpRJRk/text-split`），会自动跳转到管理员登录页 `/admin/login`。

### 安全风险

这种行为存在**信息泄露**问题：

1. **暴露管理员登录入口** - 任何人通过随机项目URL都能发现 `/admin/login` 页面
2. **暴露认证方式** - 让攻击者知道只需要密码就能登录管理员账号
3. **暴露权限模型** - 让攻击者知道管理员可以访问所有项目

### 期望行为

**区分场景处理**:
- **项目列表页** (`/`) - 跳转到管理员登录（因为这是管理员专用页面）✅ 保持原有逻辑
- **项目详情页** (`/projects/:id/*`) - **不跳转**，仅显示通用错误提示"无权访问此项目"

---

## 🔍 根因分析

### 调用链

1. 用户访问: `http://localhost:1717/projects/0P4Tj_DpRJRk/text-split`
2. `app/projects/[projectId]/layout.js` 加载
3. layout调用: `fetch('/api/projects/0P4Tj_DpRJRk')`
4. API返回401错误（无Session也无Token）
5. `lib/custom/utils/errorHandler.js` 的 `handleApiError()` 函数处理401
6. errorHandler在检测到401时，自动调用 `router.push('/admin/login')` 跳转
7. 1.5秒后页面跳转到 `/admin/login`

### 问题代码

**lib/custom/utils/errorHandler.js:64-76**
```javascript
// 401错误: 未授权 (Token无效或已过期)
if (response.status === 401) {
  const msg = errorMsg || '登录已过期,请重新登录';
  displayError(msg, setError, showAlert);

  // 延迟跳转到登录页 (给用户时间看到错误提示)
  if (router) {
    console.log(`[ErrorHandler] 401 Unauthorized, redirecting to ${loginPath} in ${redirectDelay}ms`);
    setTimeout(() => {
      router.push(loginPath);  // ← 问题：所有401都跳转，未区分场景
    }, redirectDelay);
  }

  return null;
}
```

## 🎯 解决方案

### 方案A: 区分场景处理（已选择）

**核心思路**:
- errorHandler添加 `allowLoginRedirect` 参数控制是否允许跳转
- 项目列表页: `allowLoginRedirect: true` (默认，保持原有行为)
- 项目详情页: `allowLoginRedirect: false` (禁止跳转，仅显示错误)

**实施步骤**:

1. **修改 `lib/custom/utils/errorHandler.js`**:
   - 添加 `allowLoginRedirect` 参数（默认true，向后兼容）
   - 401错误时判断是否允许跳转
   - 不允许跳转时仅显示通用错误"无权访问此项目"

2. **修改 `app/projects/[projectId]/layout.js`**:
   - 调用handleApiError时传入 `allowLoginRedirect: false`
   - 禁止项目详情页跳转到登录页

3. **保持 `components/home/HomeClient.js` 原有逻辑**:
   - 项目列表页继续使用 `allowLoginRedirect: true`（默认）
   - 管理员未登录时仍然自动跳转登录页（合理行为）
