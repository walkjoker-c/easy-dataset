## 📋 问题背景

在测试REQ-004核心功能时,用户发现两个关键问题:

### 问题1: 根目录未要求登录 🔴 高优先级

**问题描述**:
- 访问根目录 `/` 时未要求登录,直接显示项目列表
- 虽然API有鉴权,但前端页面可直接访问
- 用户可以看到UI界面,体验不佳

**根因**:
- `app/page.js` 是客户端组件,未进行服务端Session检查
- 仅依赖API级鉴权,缺少页面级保护

**安全风险**: 中等 - 虽然API有保护,但暴露了页面结构

---

### 问题2: 缺少登出按钮 🟡 中优先级

**问题描述**:
- 登录后界面上没有登出按钮
- 用户无法主动登出,只能清除Cookie

**根因**:
- TASK-009只实现了登录页面,未在主页面添加登出UI
- `/api/admin/logout` API已实现,但前端未调用

**用户体验问题**: 无法正常退出登录状态

---

## 🎯 解决方案

### 方案选择

用户选择了以下方案:

| 问题 | 方案 | 选择 |
|------|------|------|
| 根目录登录要求 | 方案A: 页面级Session检查 (服务端redirect) | ✅ 采用 |
| 根目录登录要求 | 方案B: 客户端检查 (useEffect跳转) | ❌ 未采用 |
| 登出按钮位置 | 选项1: 所有页面都显示 | ❌ 未采用 |
| 登出按钮位置 | 选项2: 仅在项目列表页显示 | ✅ 采用 |

---

### 方案A: 页面级Session检查 (服务端)

**技术方案**:
1. 将 `app/page.js` 从客户端组件改为服务端组件
2. 在服务端使用 `getSession()` 检查管理员Session
3. 未登录时使用 `redirect('/admin/login')` 重定向
4. 登录后渲染客户端组件 `<HomeClient />` (包含原有页面逻辑)

**优点**:
- ✅ 服务端渲染时直接拦截,安全性高
- ✅ 用户体验好,直接跳转登录页(无闪烁)
- ✅ 符合Next.js 14 App Router最佳实践
- ✅ SEO友好

**缺点**:
- ⚠️ 需要拆分客户端逻辑到独立组件 `HomeClient.js`
- ⚠️ 页面需要动态渲染,无法静态优化

**实施工作量**: 1.5h

**UI设计**:
- **位置**: 项目列表页面顶部 (Hero Section下方)

### 1. `app/page.js` - 页面级登录保护

**实现要点**:

```javascript
// ========== CUSTOM START ==========
// CUSTOM: 页面级登录保护 - REQ-004 补充需求
// 定制说明: 根目录页面登录保护,未登录自动跳转到管理员登录页
// 修改日期: 2025-11-18
// 功能: 检查管理员Session,未登录重定向到/admin/login
// ========== CUSTOM END ==========

import { redirect } from 'next/navigation';
import { getSession } from '@/lib/custom/auth/session';
import HomeClient from '@/components/home/HomeClient';

// 告诉Next.js此页面需要动态渲染(因为使用了cookies)
export const dynamic = 'force-dynamic';

export default async function Home() {
  // 检查管理员Session
  const session = await getSession();

  // 如果未登录,重定向到登录页
  if (!session.isAdmin) {
    console.log('[Home Page] User not logged in, redirecting to /admin/login');
    redirect('/admin/login');
  }

  console.log('[Home Page] Admin logged in, rendering page');

  // 渲染客户端组件(原有的页面逻辑)
  return <HomeClient />;
}
```

**关键点**:
- 使用 `export const dynamic = 'force-dynamic'` 支持cookies
- 服务端调用 `getSession()` 检查Session
- 使用 `redirect()` 进行服务端重定向
- 登录后渲染客户端组件

### 2. `components/home/HomeClient.js` - 登出功能

**实现要点**:

```javascript
// ========== CUSTOM START ==========
// CUSTOM: 项目列表页客户端组件 - REQ-004 补充需求
// 定制说明: 从app/page.js拆分出的客户端逻辑,添加登出按钮
// 修改日期: 2025-11-18
// 功能: 项目列表展示、管理员登出按钮
// ========== CUSTOM END ==========

'use client';

import { useRouter } from 'next/navigation';
import { Chip, Button } from '@mui/material';
import LogoutIcon from '@mui/icons-material/Logout';
import AdminPanelSettingsIcon from '@mui/icons-material/AdminPanelSettings';

export default function HomeClient() {
  const router = useRouter();
  const [loggingOut, setLoggingOut] = useState(false);

  // ========== CUSTOM: 登出功能 - REQ-004 补充需求 ==========
  const handleLogout = async () => {
    setLoggingOut(true);

    try {
      const response = await fetch('/api/admin/logout', {
        method: 'POST',
      });

      if (response.ok) {
        console.log('[Home Client] Logout successful, redirecting to login page');
        // 登出成功,刷新页面(服务端会重定向到登录页)
        router.refresh();
      } else {
        console.error('[Home Client] Logout failed:', await response.text());
        alert('登出失败,请重试');
      }
    } catch (error) {
      console.error('[Home Client] Logout error:', error);
      alert('登出失败,请检查网络连接');
    } finally {
      setLoggingOut(false);
    }
  };
  // ========== CUSTOM END ==========

  return (
    <main>
      {/* ========== CUSTOM: 管理员状态栏和登出按钮 - REQ-004 补充需求 ========== */}
      <Container maxWidth="lg" sx={{ mt: 2 }}>
        <Box sx={{
          display: 'flex',
          justifyContent: 'flex-end',
          alignItems: 'center',
          gap: 2,
          p: 2,
          bgcolor: 'success.light',
          borderRadius: 1,
        }}>
          <Chip
            icon={<AdminPanelSettingsIcon />}
            label="管理员已登录"
            color="success"
            size="small"
          />
          <Button
            variant="outlined"
            color="inherit"
            size="small"
            startIcon={<LogoutIcon />}
            onClick={handleLogout}
            disabled={loggingOut}
          >
            {loggingOut ? '登出中...' : '登出'}
          </Button>
        </Box>
      </Container>
      {/* ========== CUSTOM END ========== */}

      {/* 原有页面逻辑... */}
    </main>
  );
}
```

**关键点**:
- 登出按钮调用 `/api/admin/logout`
- 成功后使用 `router.refresh()` 刷新路由缓存
- 服务端检测到Session失效后会自动重定向到登录页
- Loading状态反馈 (`loggingOut`)
- 错误处理 (alert提示)
