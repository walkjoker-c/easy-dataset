## 📋 问题描述 (基于当前理解)

### 背景

当前存在两类项目：

**1. 公司平台项目** (有externalId):
- ✅ 管理员可以直接访问（绕过Token验证）
- ✅ 用户通过employee API + JWT Token访问
- ❌ **不应该**有其他访问方式

**2. 管理员项目** (无externalId, createdByUserId='admin'):
- ✅ 管理员登录后可以访问
- ❌ **问题**: 在无痕浏览器等新环境无法访问（需要重新登录）

### 需求

为管理员项目提供**临时访问令牌**功能：
- 管理员可以为自己创建的项目生成临时访问链接
- 链接包含临时令牌，有效期1小时
- 在无痕浏览器等新环境可以通过链接临时访问
- 过期后自动失效

## 🎯 技术方案 (初步设计，待确认)

### 方案概述

**核心思路**:
- 生成包含项目ID和过期时间的JWT令牌
- 将令牌作为URL参数传递
- authMiddleware验证临时令牌

#### Step 1: 新增临时令牌生成API

**文件**: `app/api/admin/super-token/route.js` (新建)

**功能**:
```javascript
POST /api/admin/super-token
{
  "projectId": "xxx"
}

Response:
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresAt": "2025-11-18T12:00:00Z",
  "accessUrl": "http://localhost:1717/projects/xxx?superToken=eyJhbGci..."
}
```

**令牌内容** (JWT Payload):
```json
{
  "projectId": "xxx",
  "exp": 1700308800,  // 过期时间戳
  "iat": 1700305200,  // 签发时间戳
  "type": "super-token"
}
```

**安全措施**:
- 使用密钥签名（从环境变量读取 `SUPER_TOKEN_SECRET`）
- 仅管理员可调用此API
- 仅支持管理员创建的项目（createdByUserId='admin'）

export async function authMiddleware(request, projectId) {
  // Step 1: Check Admin Session
  try {
    const session = await getSession();
    if (session?.isAdmin) {
      return { authorized: true, userId: 'admin', bypass: true };
    }
  } catch (error) {
    // continue...
  }

  // ========== CUSTOM START ==========
  // ISS-006: Step 1.5 - Check Super Token (临时访问令牌)
  const url = new URL(request.url);
  const superToken = url.searchParams.get('superToken');

  if (superToken) {
    try {
      const decoded = verifySuperToken(superToken);

      // 验证项目ID匹配
      if (decoded.projectId !== projectId) {
        return { authorized: false, status: 403, error: 'Invalid super token for this project' };

      return { authorized: false, status: 401, error: 'Invalid or expired super token' };
    }
  }

#### Step 3: 辅助函数 - 生成和验证SuperToken

**文件**: `lib/custom/auth/superToken.js` (新建)

```javascript
import jwt from 'jsonwebtoken';

const SECRET = process.env.SUPER_TOKEN_SECRET || 'default-super-token-secret';
const EXPIRES_IN = '1h';  // 1小时

/**
 * 生成超级用户临时访问令牌
 */
export function generateSuperToken(projectId) {
  const payload = {
    projectId,
    type: 'super-token',
    iat: Math.floor(Date.now() / 1000)
  };

  const token = jwt.sign(payload, SECRET, { expiresIn: EXPIRES_IN });
  const decoded = jwt.decode(token);

  return {
    token,
    expiresAt: new Date(decoded.exp * 1000).toISOString()
  };
}

/**
 * 验证超级用户临时访问令牌
 */
export function verifySuperToken(token) {
  try {
    const decoded = jwt.verify(token, SECRET);

    // 验证令牌类型
    if (decoded.type !== 'super-token') {
      throw new Error('Invalid token type');
    }

    return decoded;
  } catch (error) {
    throw new Error(`Super token verification failed: ${error.message}`);
  }
}
```

### 3. 访问URL格式

**格式**: `http://localhost:1717/projects/xxx?superToken=eyJhbGci...`

**问题**:
- Token会暴露在URL中
- 浏览器历史记录会保存Token

**风险评估**:
- ⚠️ 中等风险：Token可能被浏览器历史记录泄露
- ✅ 缓解措施：1小时过期，降低风险

**替代方案**:
- 使用POST方式传递Token（但URL不可直接分享）
- 使用一次性令牌（使用后立即失效）
