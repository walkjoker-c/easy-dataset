## 一、需求概述 ⭐

### 1.1 核心目标
在text-split页面的文件上传功能中,新增从OBS(对象存储服务)拉取文件的选项,支持用户选择从本地文件系统或OBS存储中上传文件,并实现文件导入后自动从pending目录移动到completed目录。

### 1.2 业务背景
- **现状**: 当前系统只支持从本地文件系统上传文件,用户需要先从OBS下载文件到本地,再上传到系统
- **问题**:
  - 操作流程繁琐,需要两步操作(下载→上传)
  - 对于存储在OBS中的大量文件,批量处理效率低
  - 无法跟踪OBS中的文件处理状态(已处理/未处理)
- **期望**:
  - 用户可以直接从OBS选择文件导入系统
  - 系统自动管理OBS文件状态(pending→completed)
  - 简化操作流程,提升用户体验

### 1.3 需求来源
- **提出人**: 产品经理
- **提出日期**: 2025-11-10
- **业务场景**:
  - 场景1:通过员工API创建的项目(有externalId),自动构建OBS路径并浏览文件
  - 场景2:手动创建的项目(无externalId),用户手动输入OBS路径或agentType参数
  - 场景3:文件导入完成后,自动将OBS中的文件从pending目录移动到completed目录

## 二、需求范围

### 2.1 功能需求

#### 核心功能

**功能1: 上传源选择**
- 输入: 用户点击"上传文件"按钮
- 输出: 弹出对话框,提供两个选项:"从本地上传"或"从OBS上传"
- 约束: 需要用户明确选择后才能进入下一步

**功能2: OBS环境选择**
- 输入: 用户选择"从OBS上传"
- 输出:
  - 如果项目有externalId:自动显示可选环境(dev/test/prod),选择后自动构建路径
  - 如果项目无externalId:显示输入框,用户手动输入完整OBS路径或仅输入agentType
- 约束: 必须选择或输入有效的路径信息

**功能3: OBS文件浏览器**
- 输入: 确认环境/路径后
- 输出: 显示两个文件夹视图
  - pending文件夹:显示所有未处理的文件(路径:`env={env}/messageType=conversation_data/agentType={agentType}/pending/*`)
  - completed文件夹:显示所有已处理的文件(路径:`env={env}/messageType=conversation_data/agentType={agentType}/completed/*`)
- 约束:
  - 支持文件列表展示(文件名、大小、修改时间)
  - 支持单选和全选
  - 只能从pending文件夹选择文件

**功能4: OBS文件导入**
- 输入: 用户选择文件并点击"确认"
- 输出:
  - 选中的文件显示在左侧"待上传区域"(与本地文件上传一致)
  - 用户点击"上传"按钮后,系统从OBS下载文件并处理
- 约束:
  - 下载过程需要显示进度
  - 支持批量下载
  - 下载失败需要友好的错误提示

**功能5: 文件状态自动管理**
- 输入: 文件成功导入并处理完成
- 输出: 自动将OBS中对应文件从pending目录移动到completed目录
- 约束:
  - 移动操作失败不应影响文件处理结果
  - 需要记录移动操作的日志
  - 如果completed目录不存在,自动创建

#### 扩展功能
- 支持OBS文件搜索和过滤(按文件名、文件类型)
- 支持查看OBS文件预览(针对文本文件)
- 支持从completed文件夹重新导入(重新处理场景)

### 2.2 非功能需求
- **性能要求**:
  - OBS文件列表加载时间 < 3秒
  - 单个文件下载速度根据网络环境自适应
  - 批量下载支持并发控制(建议3-5个并发)
- **安全要求**:
  - OBS访问凭证(AccessKey/SecretKey)需要加密存储
  - 不在前端日志中暴露敏感信息
  - 支持临时凭证(STS Token)访问
- **可用性要求**:
  - OBS连接失败时,降级到本地上传模式
  - 友好的错误提示(网络错误、权限错误、文件不存在等)
  - 操作流程与本地上传保持一致,学习成本低
- **兼容性要求**:
  - 支持主流OBS服务(华为云OBS、AWS S3、MinIO等)
  - 兼容现有的文件上传和处理流程

### 2.3 边界说明

#### 包含范围 ✅
- 在text-split页面增加OBS文件上传入口
- 实现OBS文件浏览器UI组件
- 实现OBS文件下载到临时目录功能
- 实现pending→completed文件移动功能
- 支持有externalId和无externalId两种项目类型
- 集成测试和用户文档

#### 不包含范围 ❌
- 不包含OBS存储空间管理功能(创建bucket、删除文件等)
- 不包含OBS文件直接预览功能(需要下载后才能预览)
- 不包含文件上传到OBS的功能(只支持从OBS下载)
- 不包含OBS访问权限管理功能
- 不包含其他页面的OBS集成(仅text-split页面)
