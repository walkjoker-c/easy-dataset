## 1. 功能概述

### 1.1 什么是OBS文件上传功能?

OBS文件上传功能允许您直接从华为云OBS对象存储导入文件到Easy Dataset,无需先下载到本地再上传。

### 1.2 功能特点

- ✅ **直接导入**: 从OBS直接拉取文件,节省本地存储空间
- ✅ **批量操作**: 支持一次选择多个文件
- ✅ **自动归档**: 处理完成的文件自动从pending移动到completed
- ✅ **进度反馈**: 实时显示下载进度
- ✅ **错误处理**: 友好的错误提示和日志记录

### 1.3 适用场景

- 文件已存储在华为云OBS上
- 需要批量处理大量文件
- 多人协作,共享OBS存储
- 自动化工作流,文件由外部系统上传到OBS

## 2. 使用步骤

### 2.1 准备工作

✅ **前置条件**:
1. 系统已配置OBS访问凭证(参考[OBS配置指南](./OBS配置指南.md))
2. OBS Bucket中已有待处理的文件
3. 项目已创建并打开

### 2.2 完整流程

```
1. 进入项目 → 2. 选择文件来源 → 3. 浏览OBS文件 → 4. 选择文件 →
5. 下载导入 → 6. 上传处理 → 7. 自动归档
```

#### 步骤详解:

**步骤1: 进入项目**
1. 在项目列表中选择目标项目
2. 点击进入项目详情
3. 切换到"文本切分"标签页

**步骤2: 选择文件来源**
1. 点击页面左侧的"选择文件"按钮
2. 在弹出的对话框中点击"OBS文件"

![上传源选择](./images/upload-source-select.png)

**步骤3: 浏览OBS文件**

根据项目类型,有两种模式:

##### 模式A: 有员工ID的项目(externalId)

1. 自动显示环境选择下拉框
2. 选择环境(Development/Test/Production)
3. 系统自动构建OBS路径: `env={环境}/messageType=conversation_data/agentType={员工ID}/`
4. 查看pending和completed文件夹

![环境选择模式](./images/obs-browser-with-env.png)

##### 模式B: 无员工ID的项目

1. 显示agentType输入框
2. 手动输入agentType(如"test-agent-001")
3. 系统构建OBS路径: `env=dev/messageType=conversation_data/agentType={输入的值}/`
4. 查看pending和completed文件夹

![手动输入模式](./images/obs-browser-manual.png)

**步骤4: 选择文件**

1. 默认显示"pending"文件夹中的文件
2. 单击文件行勾选单个文件
3. 或使用"全选"checkbox选择所有文件
4. 可以切换到"completed"文件夹查看已处理的文件
5. 点击"确认"按钮开始下载

![文件选择](./images/file-selection.png)

**步骤5: 下载导入**

1. 文件开始批量下载
2. 右下角显示下载进度: "正在下载文件: X/Y"
3. 下载完成后,文件自动显示在"待上传区域"
4. 下载失败的文件会显示错误提示

![下载进度](./images/download-progress.png)

**步骤6: 上传处理**

1. 检查待上传区域中的文件列表
2. 点击"上传"按钮
3. 文件开始处理(文本切分、生成问题等)
4. 处理过程可以在任务列表中查看

**步骤7: 自动归档**

1. 文件导入成功后,系统自动调用移动API
2. 文件从pending目录移动到completed目录
3. 移动成功后显示提示: "已将X个文件移动到completed目录"
4. 刷新OBS浏览器可以看到文件已归档

![自动归档](./images/auto-archive.png)

## 3. 文件夹说明

### 3.1 pending 文件夹

**用途**: 存放待处理的文件

**路径示例**:
```
env=test/messageType=conversation_data/agentType=emp001/pending/
```

**说明**:
- 新文件应上传到此目录
- 系统从此目录拉取文件
- 处理完成后文件会被移动到completed

**建议**:
- 文件处理前请确认文件已完整上传
- 避免上传同名文件(会被覆盖)

### 3.2 completed 文件夹

**用途**: 存放已处理的文件

**路径示例**:
```
env=test/messageType=conversation_data/agentType=emp001/completed/
```

**说明**:
- 系统自动归档已处理的文件
- 可以作为历史记录查询
- 文件不会被再次处理

**建议**:
- 定期清理旧文件释放存储空间
- 可以设置生命周期规则自动删除

## 4. 操作指南

### 4.1 选择单个文件

1. 在文件列表中找到目标文件
2. 单击文件行(或勾选checkbox)
3. 文件行高亮显示,复选框被勾选
4. 再次单击取消选择

### 4.2 批量选择文件

**方法1: 全选**
1. 勾选列表顶部的"全选"checkbox
2. 所有文件被选中
3. 再次勾选取消全选

**方法2: 逐个选择**
1. 依次勾选需要的文件
2. 已选文件数量实时显示

### 4.3 切换文件夹

1. 在文件夹选择区域,点击"Completed"标签
2. 查看已归档的文件
3. 点击"Pending"返回待处理文件

### 4.4 查看文件详情

文件列表显示以下信息:
- **文件名**: 完整文件名(支持中文)
- **大小**: 文件大小(自动转换为KB/MB)
- **修改时间**: 最后修改时间

### 4.5 取消操作

**下载前取消**:
- 点击对话框外部或"取消"按钮
- 文件选择被清空

**下载中取消**:
- 当前版本不支持取消下载
- 请等待下载完成或刷新页面

## 5. 注意事项

### 5.1 性能相关

⚠️ **大文件下载**:
- 文件越大,下载时间越长
- 建议单个文件不超过50MB
- 大文件建议分批处理

⚠️ **批量下载**:
- 系统控制并发数为3-5个
- 一次选择过多文件可能较慢
- 建议每次不超过20个文件

⚠️ **网络稳定性**:
- 网络不稳定可能导致下载失败
- 失败的文件会显示错误提示
- 可以重新选择失败的文件

### 5.2 文件管理

⚠️ **文件名冲突**:
- 不同批次的文件可以同名
- 系统按内容区分,不会覆盖

⚠️ **文件移动**:
- 移动失败不影响文件处理结果
- 移动失败的文件需手动归档
- 日志中会记录失败原因

⚠️ **文件格式**:
- 支持的格式: .md, .txt, .docx, .pdf, .epub
- 不支持的格式会被过滤
- 文件扩展名必须正确

### 5.3 权限相关

⚠️ **读取权限**:
- 确保配置的访问密钥有读取权限
- 权限不足会显示"Access Denied"

⚠️ **移动权限**:
- 需要PutObject和DeleteObject权限
- 移动失败不影响文件导入

### 5.4 其他注意事项

⚠️ **路径正确性**:
- 手动输入agentType时注意大小写
- 路径错误会导致找不到文件

⚠️ **混合使用**:
- OBS文件和本地文件可以混合处理
- 仅OBS文件会被自动归档

⚠️ **重复导入**:
- 可以重复导入同一文件
- 系统会创建新的处理记录

## 6. 常见问题

### Q1: 为什么文件列表是空的?

**可能原因**:
1. pending文件夹中确实没有文件
2. OBS路径配置错误
3. 访问权限不足
4. Bucket或文件夹不存在

**解决方法**:
1. 在OBS控制台检查文件是否存在
2. 检查环境/agentType是否正确
3. 验证访问密钥权限
4. 查看浏览器控制台的错误信息

### Q2: 下载失败怎么办?

**可能原因**:
1. 网络连接问题
2. 文件不存在或已被删除
3. 文件过大导致超时
4. OBS服务暂时不可用

**解决方法**:
1. 检查网络连接
2. 重新选择文件尝试下载
3. 大文件分批下载
4. 查看错误提示的具体原因

### Q3: 为什么文件没有自动移动到completed?

**可能原因**:
1. 移动API调用失败
2. 没有移动权限
3. 文件来自本地(非OBS)
4. completed文件夹不存在

**解决方法**:
1. 检查浏览器控制台日志
2. 验证访问密钥有PutObject和DeleteObject权限
3. OBS文件才会自动移动
4. 手动在OBS创建completed文件夹

### Q4: 可以同时选择pending和completed中的文件吗?

**A**: 不可以。每次只能在一个文件夹中选择文件。建议优先处理pending中的文件。

### Q5: 如何知道哪些文件已经处理过?

**A**:
1. completed文件夹中的文件是已处理的
2. 在项目的"已上传文件"列表中可以看到历史记录
3. 文件名相同不代表是同一次处理

### Q6: 下载的文件保存在哪里?

**A**: 文件下载后保存在浏览器内存中,不会保存到磁盘。上传处理后才会保存到项目的`local-db/projects/{projectId}/uploads/`目录。

### Q7: 如何批量上传文件到OBS pending目录?

**A**:
1. 使用华为云OBS控制台批量上传
2. 使用OBS CLI工具: `obsutil cp local-dir obs://bucket/path -r`
3. 使用OBS SDK编写上传脚本
4. 通过其他系统自动上传

### Q8: 文件移动失败会影响处理结果吗?

**A**: 不会。文件移动是独立的操作,失败只会影响归档,不影响文件的切分和问题生成。

### Q9: 能否自定义文件夹名称?

**A**: 当前版本固定为pending和completed。如需自定义,需要修改代码中的路径构建逻辑。

### Q10: 如何监控文件处理进度?

**A**:
1. 文件列表中显示"处理中"状态
2. 切换到"任务"标签查看详细进度
3. 任务完成后会显示通知

## 7. 最佳实践

### 7.1 文件组织

✅ **建议做法**:
- 按日期或批次组织pending文件: `pending/2025-11-10/file.txt`
- 使用有意义的文件名: `customer-feedback-20251110.txt`
- 定期清理completed文件夹

❌ **避免做法**:
- 不要在pending中堆积大量文件
- 不要使用特殊字符作为文件名
- 不要上传临时或测试文件

### 7.2 批处理策略

✅ **建议做法**:
- 小文件(< 1MB): 一次处理20-50个
- 中文件(1-10MB): 一次处理10-20个
- 大文件(> 10MB): 一次处理5-10个
- 超大文件(> 50MB): 逐个处理

### 7.3 错误处理

✅ **建议做法**:
- 记录失败的文件名
- 检查错误原因后重试
- 联系管理员检查权限配置

### 7.4 协作使用

✅ **建议做法**:
- 不同团队使用不同的agentType
- 使用环境区分开发/测试/生产
- 定期同步已处理文件清单

## 9. 故障排查

### 9.1 检查清单

遇到问题时,按以下清单逐项检查:

- [ ] OBS配置是否正确(.env.local)
- [ ] 网络是否正常
- [ ] 访问密钥是否有效
- [ ] Bucket权限是否足够
- [ ] 文件路径是否正确
- [ ] 文件是否存在
- [ ] 浏览器控制台是否有错误

### 9.2 日志查看

**浏览器控制台日志**:
1. 按F12打开开发者工具
2. 切换到Console标签
3. 查找包含`[OBS]`或`[UploadArea]`的日志
4. 错误日志会以红色显示

**服务器日志**:
1. 查看运行`npm run dev`的终端
2. 查找包含`[OBS]`的输出
3. 错误会显示详细堆栈信息
