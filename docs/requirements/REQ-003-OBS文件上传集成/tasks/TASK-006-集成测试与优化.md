## 六、用户文档大纲

### 6.1 配置文档

```markdown
# OBS文件上传功能配置指南

## 1. 环境变量配置

在项目根目录创建`.env.local`文件(或修改现有文件),添加以下配置:

​```bash
# OBS访问密钥
OBS_ACCESS_KEY=your-access-key-here
OBS_SECRET_KEY=your-secret-key-here

# OBS服务配置
OBS_ENDPOINT=https://obs.cn-south-1.myhuaweicloud.com
OBS_BUCKET=your-bucket-name
​```

## 2. 获取OBS凭证

1. 登录华为云控制台
2. 进入"我的凭证" > "访问密钥"
3. 创建新的访问密钥或使用已有密钥
4. 复制AccessKey和SecretKey到.env.local

## 3. 配置Bucket

确保Bucket已创建并有以下权限:
- obs:object:GetObject (读取对象)
- obs:object:PutObject (上传对象)
- obs:object:DeleteObject (删除对象)
- obs:bucket:ListBucket (列出对象)

## 4. 验证配置

运行测试脚本验证配置是否正确:

​```bash
node lib/custom/obs/test-connection.js
​```

如果看到"✅ OBS连接测试全部通过!",说明配置成功。
```

### 6.2 使用文档

```markdown
# OBS文件上传功能使用指南

## 1. 功能概述

OBS文件上传功能允许您从华为云OBS对象存储直接导入文件,无需手动下载到本地。

## 2. 使用步骤

### 2.1 选择文件来源

1. 进入项目的"文本切分"页面
2. 点击"选择文件"按钮
3. 在弹出的对话框中选择"OBS文件"

### 2.2 浏览OBS文件

**如果项目有员工ID(externalId)**:
1. 选择环境(Development/Test/Production)
2. 系统自动构建OBS路径
3. 查看pending和completed文件夹

**如果项目没有员工ID**:
1. 手动输入agentType
2. 查看pending和completed文件夹

### 2.3 选择文件

1. 在pending文件夹中选择要导入的文件
2. 支持单选或多选(勾选checkbox)
3. 可以使用"全选"快速选择所有文件
4. 点击"确认"按钮

### 2.4 文件处理

1. 文件自动下载到本地
2. 下载完成后显示在待上传区域
3. 点击"上传"按钮进行处理
4. 处理完成后,文件自动从pending移动到completed

## 3. 注意事项

- 文件下载受网络速度影响,大文件可能需要较长时间
- 同时下载多个文件时,系统会控制并发数
- 处理完成的文件会自动归档到completed目录
- 本地上传的文件不会影响OBS目录
```
