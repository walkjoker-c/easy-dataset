# Easy Dataset 部署文档

## 方式一: 直接部署 (npm)

### 场景1: 初次部署

**1. 依赖安装**
```bash
# 安装 Node.js 18.x 或更高版本
# 安装 npm 或 pnpm
```

**2. 部署流程**
```bash
# 克隆代码
git clone <repository-url>
cd easy-dataset

# 安装依赖
npm install
# 或使用 pnpm
pnpm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件,配置必要的参数

# 构建项目
npm run build

# 启动服务
npm run start
# 默认端口: 1717
```

### 场景2: 代码更新 + 数据库结构更新

**1. 拉取最新代码**
```bash
cd easy-dataset
git pull
```

**2. 更新数据库结构**
```bash
# 备份数据库
cp prisma/db.sqlite prisma/db.sqlite.backup

# 更新数据库结构 (禁止数据丢失)
npx prisma db push --accept-data-loss=false
```

**3. 重新启动服务**
```bash
# 重新构建
npm run build

# 启动服务
npm run start
```

## 方式二: Docker 部署

### 场景1: 初次部署

**1. 依赖安装**
```bash
# 安装 Docker
# 安装 Docker Compose (可选)
```

**2. 部署流程**

```bash
# 克隆代码到服务器
git clone <repository-url>
cd easy-dataset

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件,填入真实配置
```

**3. 安装依赖并初始化数据库**

```bash
# 安装依赖
npm install
# 或 pnpm install

# 初始化数据库
npx prisma db push
```

**4. 启动服务**

```bash
# 启动容器
docker run -d \
  --name easy-dataset \
  -p 1717:1717 \
  -v $(pwd)/local-db:/app/local-db \
  -v $(pwd)/prisma:/app/prisma \
  --restart unless-stopped \
  <华为云镜像仓库地址>/easy-dataset:latest

# 或使用 docker-compose
docker-compose up -d
```

### 场景2: 版本更新 + 数据库结构更新

**1. 拉取最新代码**
```bash
cd easy-dataset
git pull
```

**2. 安装依赖并更新数据库**

```bash
# 安装依赖 (如果还没安装)
npm install
# 或 pnpm install

# 备份数据库
cp prisma/db.sqlite prisma/db.sqlite.backup

# 更新数据库结构 (禁止数据丢失)
npx prisma db push --accept-data-loss=false
```

**3. 拉取最新镜像并重启**

```bash
# 拉取最新镜像
docker pull <华为云镜像仓库地址>/easy-dataset:latest

# 停止并删除旧容器
docker stop easy-dataset
docker rm easy-dataset

# 启动新容器
docker run -d \
  --name easy-dataset \
  -p 1717:1717 \
  -v $(pwd)/local-db:/app/local-db \
  -v $(pwd)/prisma:/app/prisma \
  --restart unless-stopped \
  <华为云镜像仓库地址>/easy-dataset:latest

# 或使用 docker-compose
docker-compose down
docker-compose up -d
```

## 环境变量配置说明

### 必须配置的环境变量

```bash
# ========== 数据库配置 ==========
DATABASE_URL="file:./db.sqlite"
LOCAL_DB_PATH=./local-db

# ========== Keycloak鉴权配置 (REQ-004) ==========
KEYCLOAK_INTROSPECT_URL="https://apps.dev2.aquaintelling.com/keycloak/realms/jhipster/protocol/openid-connect/token/introspect"
KEYCLOAK_CLIENT_ID="internal"
KEYCLOAK_CLIENT_SECRET="your-client-secret"

# 管理员密码 (至少8位)
ADMIN_PASSWORD="your-admin-password"

# Super User (审核员) 密码 (至少8位)
SUPER_USER_PASSWORD="your-super-user-password"

# Session密钥 (至少32字符)
SESSION_SECRET="your-session-secret-key-at-least-32-characters"

# ========== OBS对象存储配置 (REQ-003) ==========
OBS_ACCESS_KEY="your-access-key"
OBS_SECRET_KEY="your-secret-key"
OBS_ENDPOINT="https://obs.cn-south-1.myhuaweicloud.com"
OBS_BUCKET="your-bucket-name"
```

### 可选配置的环境变量

```bash
# ========== 自定义OpenAI配置 ==========
# 用于配置自定义大模型API (如Kimi-K2等)
OPENAI_CUSTOM_API_KEY="your-api-key-here"
OPENAI_CUSTOM_ENDPOINT="https://your-custom-endpoint.com/v1"
OPENAI_CUSTOM_MODEL_NAME="your-model-name"
OPENAI_CUSTOM_TEMPERATURE="0.7"
OPENAI_CUSTOM_MAX_TOKENS="16384"

# ========== 品牌定制配置 ==========
# 自定义Logo (品牌名称通过locales国际化配置)
NEXT_PUBLIC_BRAND_LOGO="/imgs/夸夸logo-05.png"

# UI功能开关 (设置为"false"隐藏对应功能)
NEXT_PUBLIC_ENABLE_PROJECT_SWITCHER="false"
NEXT_PUBLIC_ENABLE_DOCS_LINK="false"
NEXT_PUBLIC_ENABLE_GITHUB_LINK="false"

# ========== OBS默认环境配置 ==========
# 设置后将影响OBS文件浏览器的环境选择行为
# 可选值: dev | test | prod
# 留空则使用默认行为
NEXT_PUBLIC_OBS_DEFAULT_ENV=""
```

### 配置文件创建

```bash
# 复制示例配置文件
cp .env.example .env

# 编辑配置文件,填入真实的配置信息
vi .env
# 或使用其他编辑器
nano .env
```
