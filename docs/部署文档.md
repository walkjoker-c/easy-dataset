# Easy Dataset 部署文档

## Docker 部署

### 前置条件

- Docker 20.10+ 已安装
- Docker Compose 已安装

### 初次部署

**步骤1: 克隆代码**
```bash
git clone git@codehub-cn-south-1.devcloud.huaweicloud.com:b6c759891eee48fcb55ad994808bdfe9/de-dataset.git
cd de-dataset
```

**步骤2: 配置环境变量**
```bash
cp .env.example .env
vim .env  # 修改以下必需配置
```

必须修改的配置项:
- `OBS_ACCESS_KEY` - 华为云 OBS 访问密钥
- `OBS_SECRET_KEY` - 华为云 OBS 密钥
- `OBS_BUCKET` - OBS 桶名称
- `KEYCLOAK_INTROSPECT_URL` - Keycloak 认证地址
- `KEYCLOAK_CLIENT_SECRET` - Keycloak 客户端密钥
- `ADMIN_PASSWORD` - 管理员密码 (至少8位)
- `SUPER_USER_PASSWORD` - 审核员密码 (至少8位)
- `SESSION_SECRET` - Session 密钥 (至少32字符)

**步骤3: 启动服务**
```bash
docker compose up -d
```

服务将在端口 1717 启动。

> **说明**:
> - 首次启动会自动拉取远程镜像 (如可用),通常 1-2 分钟即可启动
> - 如需使用最新本地代码,请使用 `docker compose up -d --build` (构建需要 5-10 分钟)

**步骤4: 验证部署**
```bash
docker compose logs -f  # 查看日志
curl http://localhost:1717  # 测试访问
```

### 版本更新

**步骤1: 备份数据库 (可选但推荐)**
```bash
cd de-dataset
cp prisma/db.sqlite prisma/db.sqlite.backup
```

**步骤2: 拉取最新代码**
```bash
git pull
```

**步骤3: 重新启动服务**
```bash
docker compose down
docker compose up -d --build
```

> **说明**:
> - 使用 `--build` 确保使用最新代码构建镜像
> - 如果数据库结构有更新,Dockerfile 会在构建时自动执行 `prisma db push`
> - 数据库数据通过 volume 挂载持久化,不会丢失

## 环境变量配置说明

### 环境变量分层策略

本项目采用分层环境变量管理策略：

| 文件 | 用途 | Git跟踪 | 是否敏感 | 使用场景 |
|------|------|---------|---------|---------|
| `.env` | 基础配置、默认值 | ✅ 是 | ❌ 否 | 已打包进Docker镜像，提供基础配置 |
| `.env.local` | 敏感信息、环境特定配置 | ❌ 否 | ✅ 是 | 通过volume挂载或环境变量传入，覆盖`.env` |

**优势**：
- ✅ **安全**: 敏感信息不会提交到代码仓库
- ✅ **灵活**: 不同环境使用不同的 `.env.local` 文件
- ✅ **简洁**: 部署时只需配置 `.env.local` 中的敏感信息

**环境变量加载顺序**（后者覆盖前者）：
```
.env (镜像内) → .env.local (挂载/注入) → 系统环境变量
```

### 必须配置的环境变量

以下变量建议在 `.env.local` 中配置：

```bash
# ========== Keycloak鉴权配置 (REQ-004) ==========
KEYCLOAK_INTROSPECT_URL="https://apps.dev2.aquaintelling.com/keycloak/realms/jhipster/protocol/openid-connect/token/introspect"
KEYCLOAK_CLIENT_ID="internal"
KEYCLOAK_CLIENT_SECRET="your-client-secret"

# 管理员密码 (至少8位)
ADMIN_PASSWORD="your-admin-password"

# Super User (审核员) 密码 (至少8位)
SUPER_USER_PASSWORD="your-super-user-password"

# Session密钥 (至少32字符)
SESSION_SECRET="your-session-secret-key-at-least-32-characters"

# ========== OBS对象存储配置 (REQ-003) ==========
OBS_ACCESS_KEY="your-access-key"
OBS_SECRET_KEY="your-secret-key"
OBS_ENDPOINT="https://obs.cn-south-1.myhuaweicloud.com"
OBS_BUCKET="your-bucket-name"
```

### 可选配置的环境变量

```bash
# ========== 自定义OpenAI配置 ==========

NEXT_PUBLIC_OBS_DEFAULT_ENV=""
```

## Nginx 反向代理配置

如果需要通过 Nginx 反向代理访问服务，可以使用以下配置。

### 配置步骤

**步骤1: 创建 Nginx 配置文件**

```bash
sudo vim /etc/nginx/conf.d/easy-dataset.conf
```

**步骤2: 写入配置内容**

```nginx
server {
    listen 8080;  # 修改为实际监听端口
    server_name tdp.dev2.aquaintelling.com;  # 修改为实际域名，比如“dev2”换成“test”
    location / {
      proxy_pass http://192.168.0.58:1717;  # 修改为实际应用服务地址（IP:端口）
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      #proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
      #proxy_set_header X-Forwarded-Proto $scheme;
      #proxy_set_header Connection '';
      #proxy_set_header Upgrade $http_upgrade;
      #proxy_set_header Connection Upgrade;
      #chunked_transfer_encoding off;
      #proxy_read_timeout 600;
      #proxy_http_version 1.1;
      #proxy_buffering off;
      #proxy_cache off;
      add_header 'Access-Control-Allow-Origin' 'https://apps.dev2.aquaintelling.com';  # 修改为实际 Keycloak 域名
      add_header 'Access-Control-Allow-Methods' 'GET, POST, OPTIONS';
      add_header 'Access-Control-Allow-Headers' 'DNT,User-Agent,X-Requested-With,If-Modified-Since,Cache-Control,Content-Type,Range';
      add_header 'Access-Control-Expose-Headers' 'Content-Length,Content-Range';
    }
  }
```

> **注意**：需要修改的配置项：
> - `listen 8080` - 修改为实际监听端口
> - `server_name tdp.dev2.aquaintelling.com` - 修改为实际域名
> - `proxy_pass http://192.168.0.58:1717` - 修改为实际应用服务地址（IP:端口）
> - `add_header 'Access-Control-Allow-Origin' 'https://apps.dev2.aquaintelling.com'` - 修改为实际 Keycloak 域名

**步骤3: 测试配置**

```bash
sudo nginx -t
```

**步骤4: 重载 Nginx**

```bash
sudo nginx -s reload
```
