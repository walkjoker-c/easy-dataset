# Easy Dataset 部署文档

## 方式一: 直接部署 (npm)

### 前置条件

- Node.js 18.x+ 已安装
- npm 或 pnpm 已安装

### 场景1: 初次部署

**步骤1: 克隆代码**
```bash
git clone git@codehub-cn-south-1.devcloud.huaweicloud.com:b6c759891eee48fcb55ad994808bdfe9/de-dataset.git
```

**步骤2: 进入项目目录**
```bash
cd de-dataset
```

**步骤3: 安装依赖**
```bash
npm install
```

**步骤4: 创建环境配置文件**
```bash
vim .env.local
```

填入以下配置内容（根据实际环境调整）：
```bash
# ========== 敏感配置（生产环境） ==========
# OBS对象存储配置
OBS_ACCESS_KEY=your-access-key
OBS_SECRET_KEY=your-secret-key
OBS_ENDPOINT=https://obs.cn-south-1.myhuaweicloud.com
OBS_BUCKET=your-bucket-name

# 数据库配置
DATABASE_URL="file:./db.sqlite?connection_limit=1&pool_timeout=60&socket_timeout=60000"

# Keycloak鉴权配置
KEYCLOAK_INTROSPECT_URL=https://apps.dev2.aquaintelling.com/keycloak/realms/jhipster/protocol/openid-connect/token/introspect
KEYCLOAK_CLIENT_ID=internal
KEYCLOAK_CLIENT_SECRET=your-client-secret

# 管理员密码
ADMIN_PASSWORD=your-admin-password
SUPER_USER_PASSWORD=your-super-user-password

# Session密钥
SESSION_SECRET=your-session-secret-key-at-least-32-characters
```

保存并退出。

**步骤5: 初始化数据库**
```bash
npx prisma db push
```

**步骤6: 构建项目**
```bash
npm run build
```

**步骤7: 启动服务**
```bash
npm run start
```

服务将在端口 1717 启动。

### 场景2: 代码更新 + 数据库结构更新

**步骤1: 进入项目目录**
```bash
cd de-dataset
```

**步骤2: 拉取最新代码**
```bash
git pull
```

**步骤3: 安装依赖**
```bash
npm install
```

**步骤4: 备份数据库**
```bash
cp prisma/db.sqlite prisma/db.sqlite.backup
```

**步骤5: 更新数据库结构**
```bash
npx prisma db push --accept-data-loss=false
```

**步骤6: 重新构建**
```bash
npm run build
```

**步骤7: 启动服务**
```bash
npm run start
```


保存并退出。

**步骤4: 安装依赖**
```bash
npm install
```

如果安装速度慢或卡住，可以使用国内镜像源
```bash
npm install --registry=https://registry.npmmirror.com
```

**步骤5: 初始化数据库**
```bash
npx prisma db push
```

**步骤6: 拉取镜像**
```bash
docker pull swr.cn-south-1.myhuaweicloud.com/test2.0/easy-dataset:v1.20251121.1-custom-1.3
```

**步骤7: 创建启动脚本**
```bash
vim docker-up.sh
```

写入以下内容：
```bash
docker run -d \
  --name easy-dataset \
  -p 1717:1717 \
  -v "$(pwd)"/local-db:/app/local-db \
  -v "$(pwd)"/prisma:/app/prisma \
  -v "$(pwd)"/.env.local:/app/.env.local \
  --restart=unless-stopped \
  swr.cn-south-1.myhuaweicloud.com/test2.0/easy-dataset:v1.20251121.1-custom-1.3
```

保存并退出。

**步骤8: 添加执行权限**
```bash
chmod +x docker-up.sh
```

**步骤9: 启动服务**
```bash
./docker-up.sh
```

### 场景2: 版本更新 + 数据库结构更新

**步骤1: 停止并删除旧容器**
```bash
docker stop easy-dataset && docker rm easy-dataset
```

**步骤2: 进入项目目录**
```bash
cd de-dataset
```

**步骤3: 拉取最新代码**
```bash
git pull
```

**步骤4: 备份数据库**
```bash
cp prisma/db.sqlite prisma/db.sqlite.backup
```

**步骤5: 更新数据库结构**
```bash
npx prisma db push --accept-data-loss=false
```

**步骤6: 拉取最新镜像**
```bash
docker pull swr.cn-south-1.myhuaweicloud.com/test2.0/easy-dataset:<最新版本号>
```

**步骤7: 启动服务**
```bash
./docker-up.sh
```

> **注意**：如果镜像版本更新，需要先修改 docker-up.sh 脚本中的镜像版本号，然后再执行启动脚本。

## 环境变量配置说明

### 环境变量分层策略

本项目采用分层环境变量管理策略：

| 文件 | 用途 | Git跟踪 | 是否敏感 | 使用场景 |
|------|------|---------|---------|---------|
| `.env` | 基础配置、默认值 | ✅ 是 | ❌ 否 | 已打包进Docker镜像，提供基础配置 |
| `.env.local` | 敏感信息、环境特定配置 | ❌ 否 | ✅ 是 | 通过volume挂载或环境变量传入，覆盖`.env` |

**优势**：
- ✅ **安全**: 敏感信息不会提交到代码仓库
- ✅ **灵活**: 不同环境使用不同的 `.env.local` 文件
- ✅ **简洁**: 部署时只需配置 `.env.local` 中的敏感信息

**环境变量加载顺序**（后者覆盖前者）：
```
.env (镜像内) → .env.local (挂载/注入) → 系统环境变量
```

### 必须配置的环境变量

以下变量建议在 `.env.local` 中配置：

```bash
# ========== Keycloak鉴权配置 (REQ-004) ==========
KEYCLOAK_INTROSPECT_URL="https://apps.dev2.aquaintelling.com/keycloak/realms/jhipster/protocol/openid-connect/token/introspect"
KEYCLOAK_CLIENT_ID="internal"
KEYCLOAK_CLIENT_SECRET="your-client-secret"

# 管理员密码 (至少8位)
ADMIN_PASSWORD="your-admin-password"

# Super User (审核员) 密码 (至少8位)
SUPER_USER_PASSWORD="your-super-user-password"

# Session密钥 (至少32字符)
SESSION_SECRET="your-session-secret-key-at-least-32-characters"

# ========== OBS对象存储配置 (REQ-003) ==========
OBS_ACCESS_KEY="your-access-key"
OBS_SECRET_KEY="your-secret-key"
OBS_ENDPOINT="https://obs.cn-south-1.myhuaweicloud.com"
OBS_BUCKET="your-bucket-name"
```

### 可选配置的环境变量

```bash
# ========== 自定义OpenAI配置 ==========
# 用于配置自定义大模型API (如Kimi-K2等)

OPENAI_CUSTOM_MODEL_NAME="your-model-name"

# UI功能开关 (设置为"false"隐藏对应功能)
NEXT_PUBLIC_ENABLE_PROJECT_SWITCHER="false"
NEXT_PUBLIC_ENABLE_DOCS_LINK="false"
NEXT_PUBLIC_ENABLE_GITHUB_LINK="false"

# ========== OBS默认环境配置 ==========

# 可选值: dev | test | prod
# 留空则使用默认行为
NEXT_PUBLIC_OBS_DEFAULT_ENV=""
```
